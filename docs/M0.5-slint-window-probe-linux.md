# M0.5 Slint 窗口属性试验报告（Linux 侧）

> 试验工程：`experiments/slint-probe/`（独立于根 workspace，Slint 1.18.1 + winit 0.30 + software 渲染器 + x11rb 判定）。
> 运行：`cd experiments/slint-probe && env -u WAYLAND_DISPLAY cargo run -- auto`（XWayland）。
> 日期：2026-10-03，Ubuntu 24.04，GNOME Wayland 会话 + XWayland。
> 对照：Windows 侧结论见 `docs/M0.5-slint-window-probe.md`。

## 1. 试验问题

Linux 上跨端 GUI 工具包（L2 渲染路线）能否拿到候选窗必需的窗口属性：

1. **置顶**（always-on-top）
2. **显示时不抢焦点**（show 不夺前台）
3. **点击不激活**（鼠标交互不夺前台）

判定手段：x11rb 直连 X，`XGetInputFocus` 直查输入焦点，`_NET_WM_STATE` 读置顶位，
按窗口标题（HENG-HOST / HENG-CAND）辨识归属。

## 2. 结果

| 项 | 结论 | 证据 |
|---|---|---|
| T1 置顶 | **未生效（待复核）** | `always-on-top: true` 创建即设置，但 map 后 1.2s 客户端窗口 `_NET_WM_STATE` 仍无 `_NET_WM_STATE_ABOVE` 位 |
| T2 基线 | 默认 `show()` **会抢焦点** | 宿主持焦时 show 候选窗，X 输入焦点立即变为 HENG-CAND |
| T3 显示不夺前台 | **纯 Slint 不可达** | 三轮 hide/show 循环，每轮焦点均被候选窗夺走（3/3） |
| T4 点击不激活 | **待人工验证**（manual 模式） | 需要真机点击 |

### 与 Windows 侧的关键差异

Windows 上 Slint + 一层薄 shim（`SW_SHOWNA` + `WS_EX_NOACTIVATE`）即可全部达成；
Linux 上 winit **没有暴露任何不夺焦显示的 API**（`WINIT_UNIX_BACKEND` 在 0.30 已废弃，
show 路径无等价于 `SW_SHOWNA` 的开关），且 GNOME Wayland 原生窗口根本没有置顶/
免激活 API。**纯 Slint 在 Linux 不可用，必须平台 shim。**

## 3. 平台 shim 的可行路径

| 路径 | 说明 | GNOME 支持 |
|---|---|---|
| X11 override-redirect | 直连 X 建无窗口管理器干预的窗口（fcitx5 ClassicUI 同款手法），置顶/免激活/免焦点全部天然满足 | ✓（XWayland 会话） |
| wlr-layer-shell | Wayland 原生层窗口 | **✗ GNOME 至今未支持**（KDE/wlroots 支持） |
| GNOME Shell 扩展 | 加dummy 层 | 不可靠，排除 |

**结论：GNOME 是约束本身。** L2 路线在 Linux 上 = Slint 嵌入 XWayland override-redirect
窗口（或放弃 GNOME Wayland 原生会话，依赖 XWayland——与搜狗/微信/百度/讯飞给用户的
建议一致，README「需要提前接受的三件事」第 2 条已覆盖）。

对 M0.5 决策门的含义：L2 路线三端所需 shim 均为平台薄层（Windows 已实证、Linux 本报告、
macOS NSPanel 待验），但 Linux 的 shim 必须自行创建 X 窗口并把 Slint 渲染结果贴上去，
比 Windows 侧「改 show 标志 + 设扩展样式位」更厚一层。

## 4. 试验方法教训（记录在案）

- **XWayland root 的 `_NET_ACTIVE_WINDOW` 不可靠**（GNOME/mutter 维护在 Wayland 侧，
  X root 上恒空）——与 Windows 报告 §4「退化场景读数不可信」同因，改用
  `XGetInputFocus` 直查；
- **mutter 把 X11 客户端包进无标题 frame 窗口**，X 焦点常指向 frame，
  判定须递归下钻取真客户端窗口；`_NET_WM_STATE` 等属性也挂在客户端窗口上；
- **事件循环未运行时 `show()` 不会 map 窗口**（Slint 排队直到 loop 启动），
  所有窗口操作必须发生在运行中的事件循环内（试验工程用 tick 状态机解决）；
- winit 0.30 废弃 `WINIT_UNIX_BACKEND`，靠 env 存在性选择后端：
  `env -u WAYLAND_DISPLAY` 强制 X11。
